# 🎲 منصة ألعاب الطاولة والورق الذكية

منصة ألعاب عربية تفاعلية تعمل من المتصفح: شاشة تلفزيون مشتركة، وتحكّم مستقل من
جوال كل لاعب عبر QR Code، بلا تطبيق ولا تنزيل. صُممت للسهرات العائلية وألعاب
الأصدقاء، مع دعم كامل للغة العربية واتجاه RTL.

> **كل لعبة كلاسيكية لها محرّكها وطاولتها وواجهة جوالها وقوانينها المستقلة.**
> المسار العام الوحيد المتبقي هو **استوديو اللوحة المخصصة** للحزم المولّدة أو
> المستوردة، وليس قالباً يُفرض على الألعاب الكلاسيكية.

## 🌟 أبرز المزايا

### 1. محركات ألعاب مستقلة وحقيقية
- **MonopolyEngine:** نردان، ثنائيات ورمية إضافية، سجن، بناء متساوٍ، فنادق،
  إفلاس مشروط بالعجز عن السداد، وفوز بـ2000 عملة أو 4 مجموعات.
- **LudoEngine:** أربع قطع، أكل، نجوم أمان، عقوبة ثلاث رميات 6، ورمية إضافية.
- **UnoEngine:** 108 أوراق، +2 و+4، عكس وتجاوز، صرخة أونو، وسحب/تمرير آمن.
- **SnakesLaddersEngine:** 100 مربع، قفزات فورية، وارتداد عند تجاوز النهاية.
- **TerritoryEngine:** 3 أوامر لكل دور، دخل تعزيز، نرد Risk، وتحصين الأقاليم.
- **MafiaEngine:** توزيع أدوار متوازن، ليل/نهار/تصويت، ووضع مشاهدة للمُقصين.
- **ConnectFourEngine:** لوحة 7×6، جاذبية الأقراص، وكشف الفوز في 4 اتجاهات.
- **CheckersEngine:** رقعة 8×8، أكل إجباري وسلاسل أكل، وترقية الملوك.
- **BingoEngine:** بطاقات 5×5 عشوائية، 75 كرة، وفوز بأول خط مكتمل.

### 2. استوديو تصميم مرئي (`/studio`)
- محرر 20 مربعاً بأنواعها وتأثيراتها.
- محرر بطاقات اليد السرية والأحداث والدراما.
- تصدير واستيراد JSON، ومساعد ذكاء اصطناعي لتوليد حزمة كاملة.
- مسار «استوديو مخصص» منفصل تماماً عن الألعاب الكلاسيكية.

### 3. تجربة سهرة متكاملة
- انضمام فوري عبر QR Code أو رمز الغرفة.
- خصوصية كاملة: أيدي أونو وأدوار المافيا والبطاقات السرية لا تظهر إلا لصاحبها.
- بوتات ذكية تكمل العدد تلقائياً حتى الحد الأدنى للعبة.
- شريط أحداث حي، تفاعلات إيموجي، مؤثرات صوتية، واحتفال فوز.
- طاولات ثلاثية الأبعاد وأغلفة فنية محلية لكل لعبة في `public/covers/`.

## 🚀 التشغيل المحلي

### المتطلبات
- Node.js 20+
- npm

### التثبيت والتشغيل
```bash
npm install
npm run dev:all
```

يعمل الأمران معاً:
- تطبيق Next.js: `http://localhost:3000`
- خادم WebSocket: `http://localhost:1999`

أو شغّلهما منفصلين:
```bash
PORT=1999 npx tsx src/server/standalone.ts
npm run dev
```

### فحص الأنواع والاختبارات
```bash
npx tsc --noEmit
npx tsx test-all-suites.ts
```

يشغّل `test-all-suites.ts` جميع أجنحة الانحدار، بما فيها اختبارات المحركات
الحقيقية، وبروتوكول السيرفر، وسعات اللاعبين، والأغلفة المحلية.

### عرض سريع مع بوتات
```bash
npm run demo:bots
```

### فحص تشغيل كل الألعاب مع بوتات حقيقية
بعد تشغيل `npm run dev:all` في نافذة أخرى:
```bash
npm run smoke:games
```
يتحقق الأمر من بدء الألعاب التسع، وصدور حركة بوت حيّة من كل محرك.

## 🏗️ البنية المختصرة

```text
src/
  app/                 صفحات Next.js (الرئيسية، المضيف، الانضمام، الاستوديو)
  components/
    games/             طاولات العرض وواجهات الجوال المتخصصة
    monopoly/ ludo/ cards/ snakes/   مكوّنات كل لعبة
  game/
    engines/           محركات الألعاب المنفصلة
    gameRoom.ts        آلة حالة الغرفة وتنسيق الأدوار
    gameProfiles.ts    سعات اللاعبين والألوان وأسماء البوتات
    rulebooks.ts       نصوص «كيف تلعب؟» لكل لعبة
  server/
    standalone.ts      خادم WebSocket المحلي
    server.ts          خادم PartyKit
public/covers/         أغلفة SVG محلية لكل لعبة
docs/GAME_RULES.md     مرجع القواعد وطريقة اللعب وربط الكود
```

### مسار إضافة لعبة جديدة
1. أضف الحزمة في `src/game/aiPackGenerator.ts`.
2. أضف السعة في `src/game/gameProfiles.ts`.
3. اكتب محركاً في `src/game/engines/` وسجّله في `GameEngineRegistry`.
4. أضف القوانين في `src/game/rulebooks.ts`.
5. أنشئ طاولة في `src/components/games/` وواجهة جوال عند الحاجة.
6. أضف رسائل البروتوكول في الخادمين، ثم اختباراً في `test-*.ts`.
7. أضف غلافاً في `public/covers/` وسجّله في `JAWAKER_LOUNGE_GAMES`.
