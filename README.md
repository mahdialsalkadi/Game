# 🎲 استوديو ومنصة ألعاب الطاولة والورق الذكية العالمية (V2.0)
## Universal Board & Card Game Platform & Maker Studio

منصة ألعاب ويب تفاعلية واستوديو مرئي متكامل لتصميم ولعب ألعاب الطاولة والورق الحية (Board & Card Game Engine & Visual Studio) بالذكاء الاصطناعي، مستوحاة من ألعاب مثل Jackbox و Mario Party و Monopoly، مع دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL) وتصميم صوتي وفيزيائي فائق التفاعل.

---

## 🌟 أبرز المزايا المعمارية (Key Features)

### 1. 🏛️ محرك القوالب الرباعي وقواعد الفوز المتعددة (Universal Archetypes & Win Conditions)
- **سباق اللوحة السريع (`BOARD_RACE`)**: أول لاعب يصل لخط النهاية (`FIRST_TO_FINISH`).
- **اقتصاد وسهرات الصداقة (`PARTY_ECONOMY`)**: من يجمع أكبر قدر من العملة بحلول نهاية الجولات (`MOST_COINS`).
- **معارك البطاقات التكتيكية (`DECK_BATTLER`)**: أول من يحقق الرصيد المستهدف عبر سرقة وتبديل البطاقات (`TARGET_SCORE`).
- **الخيانة والخصم الاجتماعي (`SOCIAL_DEDUCTION`)**: طرد وتصفية الخصوم بالتدريج ليبقى لاعب واحد فقط (`LAST_SURVIVOR`).

### 2. 🎨 استوديو التصميم المرئي التفاعلي (`/studio`)
- **محرر المسار (Board Editor)**: تحرير 20 مربعاً تفاعلياً وتخصيص أنواعها (بداية، موارد، أفخاخ، بطاقات سرية، أحداث درامية، تصويت جماعي).
- **محرر البطاقات (Card Deck Editor)**: تصميم بطاقات اليد السرية والأحداث والدراما مع صانع تأثيرات برمجية مرئي (تعديل العملة، السرقة، القفز، التجميد، الدروع، الضرائب).
- **تصدير واستيراد فوري (JSON Export/Import)**: حفظ الحزمة بملف JSON ومشاركتها مع الأصدقاء أو رفعها للعب فوراً.
- **مساعد الذكاء الاصطناعي (AI Co-Designer)**: توليد حزمة سهرة مخصصة بالكامل بمجرد كتابة فكرة أو ثيم من سطر واحد!

### 3. 📱 شاشة لوحة كبرى تفاعلية + تحكم جوال لكل لاعب (Controller)
- مسح QR Code من كاميرا الجوال للانضمام الفوري دون تحميل أي تطبيق.
- خصوصية تامة: بطاقات اليد السرية تظهر فقط على جوال صاحبها ولا تظهر على الشاشة الرئيسية المشتركة.
- شريط أخبار عاجلة متحرك (**Live Breaking News Ticker**) يوثق كل الأحداث والخيانات لحظة بلحظة.
- تفاعلات إيموجي طافية (**Floating Reaction Physics**) تتدفق للأعلى بفيزياء جذابة وصوت رنين حيوي عند ضغط اللاعبين على شاشاتهم.
- تتويج ملكي واحتفالات بطل السهرة مع مؤثرات جزيئات ذهبية متلألئة (**Golden Confetti Celebration**).

## 🎮 دليل وطريقة اللعب (How to Play)

### الخطوة 1: تشغيل الغرفة
1. افتح الصفحة الرئيسية (`/`) واضغط على **"أنشئ غرفة جديدة"**.
2. ستفتح شاشة المضيف (`/host/XXXX`)، وتظهر اللوحة مع رمز الغرفة ورمز الـ **QR Code**.

### الخطوة 2: انضمام الأصدقاء من هواتفهم
1. يمسح كل صديق رمز الـ QR Code بكاميرا جواله (أو يدخل على `/join` ويكتب الرمز).
2. يكتب اسمه في اللعبة ويقترح فكرة أو موقفاً مضحكاً عن الشلة.
3. يظهر اسمه فوراً بلونه الخاص على الشاشة الكبرى المشتركة.

### الخطوة 3: اختيار نمط وسهرة اللعب
يختار المضيف من شاشة اللوبي أحد الخيارات:
- **✨ ابتكار بالذكاء الاصطناعي**: توليد لوحة وبطاقات مخصصة وفق أسماء ومواقف الأصدقاء.
- **🏙️ سرقة السايبر 2099**: معركة اختراق وبطاقات سريعة بهدف جمع 400 بت كوين.
- **👑 صراع سلاطين الشرق**: سهرة قوافل ومزادات تجارية يفوز فيها صاحب أكبر رصيد دنانير.
- **🏢 انقلاب المكاتب والشركات**: صراع مؤامرات وظيفية وHR حتى يبقى موظف واحد فقط!
- **📁 استيراد حزمة JSON**: رفع أي حزمة تم تصميمها في استوديو الألعاب (`/studio`).

### الخطوة 4: سير الجولة واللعب
- في دورك، يهتز جوالك ويصدر رنيناً ترحيبياً.
- يمكنك استخدام بطاقة تكتيكية سرية من يدك على أي خصم أو رمي النرد.
- يتحرك رمزك على شاشة التلفاز المشتركة قفزة بقفزة مع أصوات تفاعلية.
- عند الوقوف على مربعات التصويت الجماعي، تفتح شاشة تصويت ديمقراطي سرية مدتها 15 ثانية على جميع الهواتف لتحديد الضحية!

## 🛠️ التشغيل والتطوير المحلي (Local Development)

### المتطلبات:
- Node.js 18+ أو 20+
- npm أو pnpm

### خطوات التثبيت:
```bash
# تثبيت الحزم
npm install

# تشغيل خادم الويب سوكيت وخادم Next.js معاً
PORT=1999 npx tsx src/server/standalone.ts &
npm run dev
```
افتح المتصفح على:
- اللعبة الرئيسية: `http://localhost:3000`
- استوديو التصميم: `http://localhost:3000/studio`

### تشغيل اختبارات الجودة والانحدار (231 اختباراً - 9 أجنحة كاملة):
```bash
npx tsx test-all-suites.ts
```

## 🐳 النشر السحابي و Docker (Production Deployment)

### التشغيل عبر Docker Compose:
```bash
docker compose up -d --build
```
سيعمل التطبيق بكامل إمكانياته على:
- منفذ الويب والاستوديو: `3000`
- منفذ الويب سوكيت: `1999`
- استهلاك ذاكرة فائق الخفة: `< 200MB RAM`

### النشر بنقرة واحدة (Railway / Render / Fly.io / VPS):
- عيّن المتغير البيئي `GOOGLE_GENERATIVE_AI_API_KEY` لميزات التوليد الذكي التلقائي.
- يعمل التطبيق تلقائياً عبر الحزم الافتراضية الذكية حتى بدون إدخال مفتاح API!
